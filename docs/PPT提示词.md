# 六、如果你用 PPTD / ppt-maker 类工具链，以下三个坑必须先知道（血泪教训）

1. **画布基准不要猜。** 声明 size 为 [960, 540]，导出的 PPTX 就是 960×540 pt。
   不要因为预览图看起来「内容只占一部分」就缩小坐标——预览渲染器可能把内容放大绘制，
   从而骗过你的眼睛。**校验方式**：解压 .pptx，读 ppt/presentation.xml 的 <p:sldSz>，
   再读 ppt/slides/slideN.xml 里每个 <a:off>/<a:ext>（EMU，除以 12700 得 pt），
   确认所有形状都落在 0..960 / 0..540 内。

2. **文本框高度必须足够。** 排版引擎要求的高度约为
   `2.05 × 字号 × 行数 + 20`（pt），**与你设置的 lineHeightPx 无关**。
   只按「行数 × 行距」估算框高，会产生大量 overflow-y 阻断。
   宁可把框留高一些——**形状重叠只是 warning，不影响导出；而出界是 blocker**。

3. **行距要用固定值。** 用 `lineHeightPx`（绝对 pt），不要用 `lineHeight`（倍数）——
   倍数在 <p> 段落上会叠加出很大的间距。正文建议 lineHeightPx ≈ 字号 × 1.45，
   大字号（≥28pt）用 ≈ 字号 × 1.15。
   另外，写 `text:` 时**行内标量与块标量都要处理**（`text: 值` 与 `text: |`），
   漏掉行内标量会导致那些元素被跳过、文本框没被加高。
