# 歌曲速写扩展（song_sketch）

让 AI 真的“听”一遍某首歌，告诉它这首歌是怎么搭起来的。一个工具 `song_sketch`：

```
《Into You（VIP Mix）》— Ariana Grande / GHOST
调性：F# 小调（比较确定）
速度：约 112 BPM
能量起伏：▇█▄▁▆▅▅▁（从头到尾分 8 段）
最满的一段在 0:21–0:42，最收的一段在 1:03–1:24
音色明暗：不亮不暗
网易云：流行 · 111 BPM · 英语 · 副歌 0:02–0:36
```

- **调性**：几大调 / 几小调，附一句有多确定（常转调或调性模糊的歌会说不太确定）
- **速度**：从节拍自己算的 BPM（可能是实际的一半或两倍，和网易云标的对照着看）
- **能量起伏**：整首分 8 段，哪里最满、哪里最收
- **音色明暗**：整体偏亮还是偏暗
- **安静段**：长于 1.5 秒的安静处
- 再带上网易云音乐百科里的曲风、标签、BPM、副歌位置

## 开启

```bash
pip install numpy miniaudio
```

```
SKETCH_ENABLED=true
```

没装 numpy / miniaudio 时，这个工具不会出现，其他工具照常。和一起听扩展互相独立，开哪个都行。

## 对机器很轻

- 音频只放在内存里，听完立刻丢掉，不写文件、不缓存
- 同一时间只听一首，别的请求会被告知稍等
- 解码成单声道、11025 Hz，只用 numpy 计算：一首 3 分钟的歌内存峰值约 50MB，计算不到 1 秒，主要时间花在下载上
- 用的是普通音质（128k）；会员歌曲没有会员时只能拿到 30 秒试听，结果会注明只代表那一段

## 怎么算的

- 调性：把频谱折算成 12 个音级的分布，和 Krumhansl-Kessler 大小调模板比对
- 速度：频谱变化（起音）包络的自相关
- 能量：每 0.1 秒的响度
- 明暗：频谱重心
